**มดแดง Mot Dang** is a city directory for Chiang Mai and Chiang Rai: 88,000+ places on 27 shelves, Thai first, with drawn maps. The team builds it here.

🐜 [motdang.net](https://motdang.net) · 🏠 [sites.motdang.net](https://sites.motdang.net) · 🔌 [API](https://motdang.net/api/) · 🗺️ [map doodles](https://motdang.net/sites/map-doodles/) · ✉️ hello@motdang.net
